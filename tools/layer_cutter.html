What are you making?

Puppet rig = cut parts + pin joints + set swing (what SUPER X uses). Face expressions = cut a face's features (brows, eyes, mouth…) once, then pose happy / sad / angry / shocked by nudging them. Cut in Puppet-rig mode, then switch here to pose the faces.

Tool

🩹 Patch base rebuilds the coat/belt hidden behind a mover, so when it swings away you see real texture — not a gap. Picking this tool lifts the movers off so the area behind them glows magenta (that's what you're rebuilding; the magenta recedes as you paint). Tap 🎯 Set source spot → tap a clean patch of belt/coat → then paint over the magenta: every stroke copies that same spot's texture (it stays put until you pick a new spot). Painting is clipped to the area behind the mover + the figure, so you can't smear outside it. It paints onto a non-destructive back-layer under the base (never touches the mover) and bakes under the base on export. ↩︎ / ⌘Z undoes any patch.

Two fingers (or mouse-wheel) to zoom & pan. The coloured overlay shows what's selected. Switch the wand to ✖ removes to un-select a wrong flood — or just ↩︎/↪︎ in the top bar (⌘Z / ⇧⌘Z) to undo/redo any step. Pivot = the joint the part rotates around.

Clean up the selection

Knock-out white flood-fills the connected white background and keeps everything else — the fast first cut. Then Brush/Erase to fix, Grow to catch the soft pencil edge, Shrink/Feather to tidy.

Layers (back → front)

base = the body, stays still & joined. mover = a limb you'll animate — cut it OFF the body itself (not a separate study, or it won't line up), tick “cut out” so its shape is lifted off whatever it sits on (the base, or the layer it Swings with), and pin its 🎯 joint (shoulder/hip/neck). Use ▲▼ on a row to order front/back. Then ▶ Preview motion to watch the whole figure assemble + swing.

Motion (selected mover)

Angle = how far it swings, Speed = how fast. Tuck to body nudges the part a few px toward the torso so the empty cut area (e.g. behind the right hand) stays hidden. Changes show live in ▶ Preview.

Expressions

whole face, one tap · MLS-rigid mouth curl
Edit:
Pick an expression, then draw its mouth — tap left→right along the lip you want (green).

Draw each expression's mouth directly: tap 🙂 Happy → draw the smile; tap ☹️ Sad → draw the frown; etc. The mouth warps to the line you draw, live. Neutral = trace where the mouth rests (the source the others bend from) — optional; if you skip it a straight baseline is used. 3–6 points. Needs the mouth named mouth / lip / dudak. (The ✨ FACS auto-pose button still auto-shapes any expression you'd rather not draw by hand.)

Tool:

Pick an expression, then tap ✨ FACS auto-pose for a believable whole-face start (needs features named brow / eye / mouth), and tweak from there. Or pose by hand: ▦ Box moves / rotates / stretches the whole part. 🫠 Warp an area: ⭕ Region = drag a circle over an area (the eye) then Zoom / Rotate just that area with a soft edge; 📍 Point = tap to drop a point and drag to pull it. Neutral is the resting face. ↩︎ undo / ⌘Z covers all of these. ▶ Preview morphs through them. Tip: tick cut out (on the feature's row) so it's lifted off the head — its old spot won't ghost when it moves.

Export

Names the exports: <name>_layers.zip, <name>_face_frames.zip, <name>.ogcut.json.

Send to app hands the layers + rig straight to the host app (it bakes the moving puppet, no files to pass around). Export .zip is the manual route: one transparent PNG per layer, the base with mover-holes punched, and rig.json.
