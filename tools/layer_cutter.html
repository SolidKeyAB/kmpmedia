What are you making?

Puppet rig = cut parts + pin joints + set swing (what SUPER X uses). Face expressions = cut a face's features (brows, eyes, mouth…) once, then pose happy / sad / angry / shocked by nudging them. Cut in Puppet-rig mode, then switch here to pose the faces.

Tool

Two fingers (or mouse-wheel) to zoom & pan. The coloured overlay shows what's selected. Switch the wand to ✖ removes to un-select a wrong flood — or just ↩︎/↪︎ in the top bar (⌘Z / ⇧⌘Z) to undo/redo any step. Pivot = the joint the part rotates around.

Clean up the selection

Knock-out white flood-fills the connected white background and keeps everything else — the fast first cut. Then Brush/Erase to fix, Grow to catch the soft pencil edge, Shrink/Feather to tidy.

Layers (back → front)

base = the body, stays still & joined. mover = a limb you'll animate — cut it OFF the body itself (not a separate study, or it won't line up), tick “punch” so its shape is removed from the base, and pin its 🎯 joint (shoulder/hip/neck). Use ▲▼ on a row to order front/back. Then ▶ Preview motion to watch the whole figure assemble + swing.

Motion (selected mover)

Angle = how far it swings, Speed = how fast. Tuck to body nudges the part a few px toward the torso so the empty cut area (e.g. behind the right hand) stays hidden. Changes show live in ▶ Preview.

Expressions

Pick an expression, then drag a feature on the canvas (or use the nudges / Rotate / Scale below) to pose it — e.g. brows down&in = angry, brows up + mouth open = shocked. Neutral is the resting face. ▶ Preview morphs through them all. Tip: tick punch on each feature so its old spot doesn't ghost when it moves.

Export

Send to app hands the layers + rig straight to the app over nexum (I bake the moving puppet, no files to pass around). Export .zip is the manual route: one transparent PNG per layer, the base with mover-holes punched, and rig.json.
